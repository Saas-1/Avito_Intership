# Тест-кейсы для API микросервиса объявлений

## 1. Создание объявлений (POST /ads)

### Создание объявления с валидными данными
- **Предусловие**: Подготовлены корректные данные объявления (title, description, price, sellerId, itemId)
- **Шаги**:
  1. Отправить POST запрос на /ads с валидными данными объявления
- **Ожидаемый результат**:
  - Статус код: 201
  - В теле ответа содержится ID созданного объявления
  - ID является целым числом

### Создание объявления без обязательных полей
- **Предусловие**: Подготовлены данные объявления с отсутствующим обязательным полем (например, без title)
- **Шаги**:
  1. Отправить POST запрос на /ads с неполными данными
- **Ожидаемый результат**:
  - Статус код: 400
  - В теле ответа содержится информация об ошибке

### Создание объявления с некорректной ценой
- **Предусловие**: Подготовлены данные объявления с отрицательной ценой
- **Шаги**:
  1. Отправить POST запрос на /ads с данными, содержащими отрицательную цену
- **Ожидаемый результат**:
  - Статус код: 400
  - В теле ответа содержится информация об ошибке валидации

### Создание объявления с пустым описанием
- **Предусловие**: Подготовлены данные объявления с пустым полем description
- **Шаги**:
  1. Отправить POST запрос на /ads с данными, содержащими пустое описание
- **Ожидаемый результат**:
  - Статус код: 201
  - В теле ответа содержится ID созданного объявления

## 2. Получение объявления по ID (GET /ads/{id})

### Получение существующего объявления
- **Предусловие**: В системе существует объявление с известным ID
- **Шаги**:
  1. Отправить GET запрос на /ads/{id}, где id - известный ID объявления
- **Ожидаемый результат**:
  - Статус код: 200
  - В теле ответа содержатся все данные объявления (id, title, description, price, sellerId, itemId)

### Получение несуществующего объявления
- **Предусловие**: Подготовлен ID объявления, которого нет в системе
- **Шаги**:
  1. Отправить GET запрос на /ads/{id}, где id - несуществующий ID
- **Ожидаемый результат**:
  - Статус код: 404
  - В теле ответа содержится информация об ошибке

### Получение объявления с некорректным форматом ID
- **Предусловие**: Подготовлен некорректный формат ID (например, строка вместо числа)
- **Шаги**:
  1. Отправить GET запрос на /ads/{id}, где id - некорректный формат ID
- **Ожидаемый результат**:
  - Статус код: 400
  - В теле ответа содержится информация об ошибке формата

## 3. Получение объявлений по ID продавца (GET /ads/sellers/{sellerId})

### Получение объявлений существующего продавца
- **Предусловие**: В системе есть продавец с несколькими объявлениями
- **Шаги**:
  1. Отправить GET запрос на /ads/sellers/{sellerId}, где sellerId - ID существующего продавца
- **Ожидаемый результат**:
  - Статус код: 200
  - В теле ответа содержится массив объявлений данного продавца
  - Каждое объявление содержит все необходимые поля

### Получение объявлений несуществующего продавца
- **Предусловие**: Подготовлен ID продавца, которого нет в системе
- **Шаги**:
  1. Отправить GET запрос на /ads/sellers/{sellerId}, где sellerId - несуществующий ID продавца
- **Ожидаемый результат**:
  - Статус код: 200
  - В теле ответа содержится пустой массив

### Получение объявлений с некорректным форматом ID продавца
- **Предусловие**: Подготовлен некорректный формат ID продавца (например, строка вместо числа)
- **Шаги**:
  1. Отправить GET запрос на /ads/sellers/{sellerId}, где sellerId - некорректный формат ID
- **Ожидаемый результат**:
  - Статус код: 400
  - В теле ответа содержится информация об ошибке формата

- **Ожидаемый результат**:

  ИЛИ
  - Статус код: 404
  - В теле ответа содержится информация об ошибке

### Получение статистики с некорректным форматом item ID
- **Предусловие**: Подготовлен некорректный формат item ID (например, строка вместо числа)

## 5. Граничные случаи и бизнес-логика

### Создание нескольких объявлений одним продавцом
- **Предусловие**: Подготовлены данные для нескольких объявлений с одним sellerId
- **Шаги**:
  1. Создать несколько объявлений с одним sellerId
  2. Получить все объявления данного продавца
- **Ожидаемый результат**:
  - Все объявления успешно созданы (статус код 201)
  - При запросе объявлений продавца все созданные объявления присутствуют в ответе

### Создание объявления с очень большими значениями полей
- **Предусловие**: Подготовлены данные объявления с очень длинным заголовком, описанием и большой ценой
- **Шаги**:
  1. Отправить POST запрос на /ads с данными, содержащими очень большие значения
- **Ожидаемый результат**:
  - Система должна корректно обработать запрос (принять или отклонить с понятной ошибкой)
  - Если принимает - объявление должно быть доступно по ID
