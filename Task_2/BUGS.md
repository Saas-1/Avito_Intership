
# Отчет о найденных багах

## Некорректная обработка отрицательной цены при создании объявления

### Описание
При создании объявления с отрицательной ценой API принимает запрос и создает объявление вместо возврата ошибки валидации.

### Шаги воспроизведения
1. Отправить POST запрос на /ads с телом:

{
  "title": "Test Ad with Negative Price",
  "description": "This ad has a negative price",
  "price": -100,
  "sellerId": 123456,
  "itemId": 1234567
}

### Фактический результат
- Статус код: 201
- Объявление успешно создано с отрицательной ценой

### Ожидаемый результат
- Статус код: 400
- Ошибка валидации о некорректном значении цены



## Отсутствует проверка обязательных полей при создании объявления

### Описание
API позволяет создать объявление без указания обязательных полей (например, без title или без price).

### Шаги воспроизведения
1. Отправить POST запрос на /ads с неполным телом:

{
  "description": "This ad has no title",
  "price": 100,
  "sellerId": 123456,
  "itemId": 1234567
}

### Фактический результат
- Статус код: 201
- Объявление успешно создано без обязательного поля

### Ожидаемый результат
- Статус код: 400
- Ошибка о том, что отсутствует обязательное поле


## Некорректная обработка запроса статистики для несуществующего item ID

### Описание
При запросе статистики для несуществующего item ID API возвращает 404 вместо пустой статистики с нулевыми просмотрами.

### Шаги воспроизведения
1. Отправить GET запрос на /stats/9999999999 (где 9999999999 - заведомо несуществующий item ID)

### Фактический результат
- Статус код: 404
- Сообщение об ошибке

### Ожидаемый результат
- Статус код: 200
- Статистика с нулевыми просмотрами:

{
  "itemId": 9999999999,
  "views": 0
}
